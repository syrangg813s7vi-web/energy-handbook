# RK3588 AI边缘计算盒：硬件能力与厂家应用主张

截图中的产品高度疑似G6-RK3588-F13平台的经销或OEM版本。本质上是一台带独立NPU的ARM工控机，主要用于现场视频处理、AI推理和工业设备接入。

## 硬件配置

| 项目 | 配置 |
|---|---|
| 处理器 | Rockchip RK3588，4×Cortex-A76 + 4×Cortex-A55 |
| GPU | Mali-G610 MP4 |
| NPU | 三核NPU，标称6 TOPS |
| 内存 | 8GB或16GB |
| 内置存储 | 64GB或128GB eMMC |
| 扩展存储 | M.2 2280 SATA/NVMe SSD |
| 视频能力 | 厂家宣称最高支持8路1080P/30fps硬解码 |
| 网络 | 双千兆网口；Wi-Fi、蓝牙、4G/5G视配置选配 |
| 外设接口 | 2×USB 3.0、4×USB 2.0、2×RS232、2×HDMI及音频接口 |
| 操作系统 | Ubuntu 22.04、Debian 11或Android 12 |

具体内存、存储、无线模块、RS485及HDMI输入/输出功能，应以所购SKU为准。

## AI硬件能力与适用应用

| 能力 | 说明 |
|---|---|
| AI算力 | NPU标称6 TOPS，主要用于模型推理，不用于训练 |
| 部署方式 | 模型经RKNN工具链转换和量化后在NPU上运行 |
| 视频AI链路 | 视频硬解码 → RGA图像预处理 → NPU推理 → 业务告警 |
| 适合的模型 | 轻量YOLO、图像分类、人脸/车牌识别、OCR、轻量分割、姿态识别、目标跟踪及部分语音模型 |
| 模型规模定位 | 以小型、轻量化视觉模型为主；量化小语言模型可尝试，但不是主要定位 |
| 适合场景 | 多路摄像头分析、工业质检、机器人视觉、离线识别和智能网关 |
| 不适合场景 | 模型训练、大型语言模型服务及大型生成式图像/视频任务 |

“8路视频硬解码”不等于“8路视频均可进行30fps AI分析”。实际并发能力取决于模型、输入分辨率、量化精度、分析帧率、软件优化和散热条件。

## 厂家宣称支持的AI应用

| 应用领域 | 厂家宣称的功能 |
|---|---|
| 智慧安防 | 人脸识别、车牌识别、行为分析、入侵检测、烟火识别、人员聚集预警、安全帽检测、车辆识别 |
| 机器人视觉 | 障碍物识别、定位、路径规划、SLAM、避障、环视和深度感知 |
| 工业质检 | YOLOv8目标检测、划痕/裂纹检测、异物识别、产品外观和打印过程缺陷检测 |
| 物流分拣 | 包裹识别、PaddleOCR文字识别、3D尺寸测量、异常包裹检测 |
| 智慧农业 | 作物与杂草识别、果实成熟度判断、病虫害识别 |
| 畜牧水产 | 牲畜行为分析、异常个体识别、鱼群状态分析、船舶和无人机跟踪 |
| 园区与教育 | AI考勤、课堂行为分析、出入口管控、重点区域监测 |

厂家宣称“支持”上述场景，不代表基础售价版本已经预装全部算法。购买前应要求卖家现场演示从摄像头接入、算法配置到告警输出的完整流程。
