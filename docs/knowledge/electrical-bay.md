# 电气间隔：把一条电气连接变成可管理单元

> **间隔（Bay）不是一只开关，也不是一面柜子，而是围绕一条母线连接支路形成的、可以独立监视、操作、保护和检修的电气功能单元。**

一座新能源升压站可能有几十条集电线路、主变、母联和送出线路。如果它们不能分开管理，一条集电线路短路就可能迫使整段母线甚至全站停运。间隔的价值，就是把复杂的一次系统切成多个边界明确的自治单元：正常时独立投退，故障时尽量只切除最小范围，检修时建立可靠隔离。

最实用的识别方法是：从母线向外看，一条具有明确连接对象和开断边界、能独立投退的支路，通常就是一个间隔。特殊接线可能共享断路器或测量设备，因此这是工程判断方法，不是死板的设备数量公式。

| 监控与通信通道 | 间隔 IED ↔ 站控/远动 ↔ 调度/HMI | 遥测、遥信、遥控、告警、事件和品质 | 间隔层执行，站控层协调 |

### 命令怎样闭环

以站控发出“分闸”为例：

```text
操作员/调度发出请求
  → 站控或远动确认控制权、站级条件
  → 间隔控制器检查本间隔联锁
  → 跳闸回路使断路器分闸
  → 辅助接点返回分位
  → 间隔层判定成功、失败或超时
  → 结果、时间戳和品质上送站控/调度
```

命令发出不等于动作成功。闭环成立的标志，是实际位置和电流状态被重新采集并确认。

保护动作更强调本地自治。短路发生后，CT/VT把电气量送给保护 IED，IED按保护定值判断并直接发出跳闸，断路器切断故障电流；告警和录波随后上送。即使站控服务器或 HMI 暂时失联，本地保护仍应能够工作。

### 各层各自回答什么问题

| 层级 | 主要问题 | 典型时间特征 |
|---|---|---|
| 一次设备/过程层 | 电流怎样被测到、命令怎样落到线圈、主电流怎样被切断 | 从电磁暂态到毫秒级动作 |
| 间隔层 | 本支路是否故障、是否允许操作、动作是否成功 | 毫秒级保护到秒级操作确认 |
| 站控层 | 全站有哪些间隔、如何统一监视、跨间隔条件是否满足 | 事件与运行协调 |
| 调度/场站控制 | 电站接入方式和全局目标是什么 | 运行计划到秒级连续调节 |

PPC 的有功、无功、电压或功率因数闭环跨越多个发电单元，属于场站级连续控制。它可以读取间隔状态作为可用条件，但不应与本间隔的开关操作闭环混为一谈。

## 一个完整间隔由什么组成

设备布置会随电压等级、AIS/GIS/开关柜和一次接线变化，但下列功能必须被落实。

### 1. 连接对象和电气边界

间隔首先要回答“这组设备为谁服务”：一条集电馈线、一条送出线路、主变的一侧、两段母线之间的母联，或一个电容器组。没有明确对象和保护/操作边界，站控点表、保护范围和跳闸对象就无法一致。

### 2. 断路器：负责开断电流

断路器能在正常负荷下分合，并在短路时切断很大的故障电流。它依靠灭弧介质和操作机构，在触头分离时熄灭电弧。

保护 IED 只负责判断并给出跳闸命令，真正切断主电流的是断路器。若缺少开断能力，支路不能独立退出，保护即使识别出故障也没有最终执行器。

### 3. 隔离开关：负责建立检修隔离

隔离开关在电流已经被断路器切除后，形成可确认的电气断口。它通常没有足够的灭弧能力，不能把“拉刀闸”当作切负荷或切短路的手段。

若只有断路器而没有满足规程的隔离措施，运行上可以停电，却未必形成可安全检修的隔离边界。中压开关柜或 GIS 可能把隔离功能集成在组合设备中，不能据此认为隔离功能消失。

### 4. 接地刀闸：负责把检修区保持在地电位

设备断电、隔离并验电后，接地刀闸把检修部分可靠接地，释放残余电荷，并防范邻线感应、雷电感应、对端误送电或发电设备反送电。

它不能带电合上，否则相当于把带电导体直接接地。因此“隔离开关分位、断路器分位、确认无电”等条件必须通过机械、电气和逻辑联锁共同约束。

### 5. CT 与 VT/CVT：把一次量变成可用信息

CT 将一次大电流按比例转换为保护、测量和计量可使用的电流；VT/CVT将高电压转换为可测量电压。保护 IED据此计算过流、差动、距离、电压、频率等判据，站控系统据此显示电流、电压、功率和电能。

没有正确的测量链，保护系统就“看不见”一次系统。需要注意：每条支路通常有自己的 CT，但母线 VT 可以被多个间隔共享；这里不可缺的是可靠的电流/电压信息来源，不一定是每个间隔独享一套物理 VT。

### 6. 保护 IED：在故障发生后快速切除

保护 IED 持续读取电流、电压和状态，执行过流、差动、距离、接地、失灵等算法。条件满足时，它通过硬接点或 IEC 61850 GOOSE 发出跳闸，同时记录事件和故障波形。

若没有保护功能，故障只能依赖上级后备保护清除，动作更慢、切除范围更大。特殊的 PT/VT 或避雷器间隔未必配置完整跳闸保护，所以“保护必需”主要针对承担输送、变换或补偿功能的重要间隔。

### 7. 间隔控制与联锁：在误操作发生前阻止它

间隔控制器采集断路器、隔离开关、接地刀闸、储能、气压、控制电源和就地/远方控制权，执行分合闸、顺序和本间隔联锁，并检查位置是否在规定时间内到达。

联锁与保护的区别很简单：联锁在危险操作发生前拒绝命令，保护在电气故障发生后切除故障。关键条件不能只放在站控软件中：设备机械闭锁、电气硬接线、本间隔逻辑、跨间隔站级逻辑和五防各自承担不同失效场景。

### 8. 跳合闸回路、直流电源和辅助接点：让判断落到现实

跳闸线圈、合闸线圈、出口继电器、端子、压板、辅助接点和可靠直流电源构成“最后一公里”。它们把 IED 的小信号变成机构动作，并把真实位置送回控制系统。

这些部件经常不出现在高层架构图中，却是动作链最容易被忽略的部分。没有独立可靠的操作电源和位置反馈，“算法正确”仍不能证明断路器真的动作。

### 9. 通信、时间同步和工程配置：让多个设备说同一种话

传统方案可用铜缆把 CT/VT、开关量和跳闸回路直接接到 IED。数字化方案中，合并单元在现场发布 IEC 61850 Sampled Values，IED通过 GOOSE交换快速状态或命令，通过 MMS向站控层提供模型、测量、事件和控制服务；与调度的北向接口常由远动网关使用 IEC 60870-5-104 等规约完成。

统一时间用于 SOE 排序、录波对齐和跨设备故障分析。工程文件则规定保护定值、I/O映射、逻辑、通信数据集和版本。通信或配置不可追溯时，系统即使“在线”，也未必传的是正确对象和正确语义。

## 为什么这些组件不能互相替代

| 如果缺少 | 直接后果 | 为什么别的组件补不上 |
|---|---|---|
| 断路器/等效开断器 | 故障支路不能快速独立切除 | 隔离开关通常不能开断故障电流 |
| 隔离功能 | 难以建立可靠检修边界 | 断路器分位不自动等于安全隔离 |
| 接地功能 | 残余、感应或误送电仍可能危及人员 | 隔离只断开电源，不把检修区固定到地电位 |
| 电流/电压信息 | 保护与测量失去依据 | 软件不能凭空知道一次量 |
| 保护判断 | 故障依赖慢速、扩大范围的后备切除 | 站控 HMI 不适合承担毫秒级安全保护 |
| 联锁与控制确认 | 危险命令可能被执行，或执行失败无人确认 | 保护不负责所有正常操作条件 |
| 操作电源、线圈、出口和反馈 | 命令不能落地或无法确认 | 通信成功不等于机械动作成功 |

这里的“不缺少”是功能合同，不是要求每个间隔物理独享所有设备。母线 VT、母线保护、站控服务器和一个半断路器接线中的断路器都可能被共享；数字化或组合电器也会把多个功能集成到同一设备中。

## 间隔怎样分类

最清楚的分类方式，是看它连接什么对象、要解决什么问题。

| 间隔类型 | 连接对象与主要作用 | 常见保护/控制重点 |
|---|---|---|
| 馈线/集电线路间隔 | 连接中压负荷、光伏、风电或储能集电线路 | 过流、速断、接地，必要时线路差动 |
| 送出线路间隔 | 连接本站与远方电网或其他站 | 线路差动、距离、方向接地、重合闸、失灵 |
| 主变间隔 | 把主变某一侧接入对应电压等级母线 | 变压器差动配合、后备过流、非电量联动 |
| 母联/分段间隔 | 连接或分开同电压等级的两段母线 | 同期、充电、备自投/运行方式及跨间隔联锁 |
| 电容器间隔 | 投切电容器组，提供容性无功 | 过流、过压、不平衡及投切控制 |
| 电抗器间隔 | 吸收无功或限制短路电流 | 差动、过流、温度及投切控制 |
| 站用变/接地变间隔 | 提供站用电或系统中性点 | 过流、接地、温度及备用切换 |
| 发电机/调相机间隔 | 把旋转电机接入母线 | 差动、失磁、逆功率、失步、同期 |
| PT/VT 间隔 | 向母线测量、同期和保护提供电压 | 电压回路监视、熔断/隔离；通常无主断路器 |
| 避雷器间隔 | 限制雷电和操作过电压 | 状态监测，结构通常较简单 |

一台主变可能对应高压侧、低压侧甚至中压侧多个间隔；一个母联间隔连接的是两段母线，并不连接外部线路。由此也能看出，间隔是功能划分，而不是“每条线路一只开关”的同义词。

一次设备本身——断路器、隔离/接地功能、CT/VT、GIS或中压开关柜——还需要按电压等级、开断能力、绝缘介质、接线方案和项目认证单独选型。SIPROTEC负责“看见、判断和发命令”，SICAM负责“汇聚、协调和显示”，真正承载与切断主电流的仍是一次设备。

### 一次短路时，产品怎样协同

以 220 kV 送出线路为例：

```text
线路 CT/CVT
  → 6MU85 发布采样值（或模拟铜缆直接进入保护）
  → 7SA/7SD/7SL 判断区内故障
  → 硬接点或 GOOSE 触发跳闸回路
  → 线路断路器分闸
  → 辅助接点和电流返回，确认故障被切除
  → 事件经 IEC 61850 上传 SICAM PAS/S8000
  → SCC/HMI 显示告警，DISTO取回录波，SIGRA辅助分析
```

这条链揭示了间隔设计的本质：每个产品只承担自己必须可靠完成的一环，系统安全来自测量、判断、执行、确认和上送之间的完整闭环，而不是来自某一台“万能设备”。

## 记住这四句话

1. **间隔是一条可独立管理的电气连接，不是一只开关。**
2. **断路器负责开断，隔离开关负责检修隔离，接地刀闸负责检修接地。**
3. **保护和本间隔联锁尽量本地自治，站控负责全站监视和跨间隔协调。**
4. **功能不能缺，但物理设备可以共享、集成或虚拟化。**
