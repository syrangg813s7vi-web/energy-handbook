# LightGBM负荷预测动画文章设计

## 功能范围

新增面向零基础读者的知识文章，用同一组负荷预测数据解释：

1. 回归决策树如何选择特征和阈值；
2. Boosting与GBDT为什么增加多棵树；
3. LightGBM如何保持GBDT目标并加速训练；
4. 训练完成后如何预测。

## 层与公共合同

### 1. Markdown文章层

职责：完整叙事、公式、案例数值、算法边界、参考资料和无JavaScript降级。

公共合同：只通过稳定的`/demos/load-forecasting/*.html`路径引用动画。

禁止依赖：不得读取动画内部DOM，不得复制动画的步骤状态。

### 2. 原版动画层

职责：显示树结构、阈值竞争、残差更新、直方图与Leaf-wise过程。

公共合同：自包含HTML，提供原生按钮和可访问标签；不发出网络请求。

禁止依赖：不得依赖VitePress、Vue组件、文章DOM或服务端状态。

### 3. 嵌入层

职责：使用iframe提供隔离、延迟加载、标题和固定的响应式展示高度。

禁止依赖：不得二次绘制动画或重新实现算法。

### 4. 导航层

职责：从首页、顶部导航和“能源基础”侧边栏进入文章。

禁止依赖：不得包含算法数据或训练状态。

## 文章结构

- 开篇：一句话解释、演进、提出背景、贯穿数据。
- 回归树：特征、候选阈值、SSE评分、下一层与叶子均值。
- Boosting/GBDT：初始值、残差/负梯度、两棵修正树、学习率、加法预测。
- LightGBM：直方图、增益、叶子值、新树、停止，以及Leaf-wise、GOSS、EFB、类别与缺失值。
- 预测：新样本依次通过全部树并累加输出。

## 验收与回滚

- 运行项目已有的自动化测试和生产构建。
- 检查生成页面包含文章标题及四个演示路径。
- 检查四个发布HTML包含原版根节点和交互脚本。
- 发布后检查文章及四个演示的HTTP状态。
- 回滚只删除新增文章与演示，并恢复三个导航入口。

## 恢复

文章、动画、导航和设计文件全部以远端Git仓库为权威来源。干净机器执行`npm ci && npm run check`即可恢复构建；发布由现有GitHub Pages工作流重建。
